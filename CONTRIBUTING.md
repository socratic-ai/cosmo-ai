# Contributing

This repository is a read-only mirror. Development happens in Cosmo's
internal repository; each release is exported here as a single commit
(see the `Monorepo-commit` trailer).

Bug reports and feature requests: please open an issue. Pull requests
are welcome too — accepted changes are imported internally with
`Co-authored-by` credit and appear in the next release rather than being
merged here directly.

A fuller contribution guide ships with the public launch.
